# Open price datasets

Machine-readable exports of the price and terms tables published on ServerBudget. Each row keeps the official provider URL it was transcribed from, so every figure traces back to its source.

These tables are published alongside the human-readable comparisons at https://serverbudget.com/compare.

## Files

| File | Rows | What it contains |
|---|---:|---|
| `vps-plan-pricing.csv` | 9 | Three published tiers at DigitalOcean, OVHcloud and ScalaHosting, with per-GB/per-vCPU unit prices |
| `vps-addon-costs.csv` | 15 | Backup, snapshots and dedicated IPv4 terms as printed on each provider's page |
| `vps-price-vs-renewal.csv` | 3 | Headline price next to the renewal price where one is published |
| `renewal-price-comparison.csv` | 10 | First-term vs renewal at eight providers, with the exact source wording |
| `coupon-offers.csv` | 133 | Promo offers across 26 provider pages, with conditions and official source URL |
| `datacenter-region-pricing.csv` | 6 | Entry to 8-vCPU tier prices by datacenter city |
| `contract-term-total-cost.csv` | 4 | What a 1/12/24/36-month term actually costs |
| `entry-tier-pricing.csv` | 4 | Cheapest tier, hourly and monthly side by side |
| `provider-payment-methods.csv` | 48 | What each of six provider pages actually prints for cards, PayPal, crypto, Alipay/UnionPay, currency and regional restrictions |
| `backup-tier-terms.csv` | 7 | Trigger, retention window and price for each published backup tier, plus what the copy does not cover |
| `included-transfer-allowances.csv` | 3 | Traffic allowance per provider as printed, and how the allowance is attached |
| `storage-extension-costs.csv` | 4 | Disk add-on price, billing unit and growth rules as printed per provider |
| `bandwidth-overage-units.csv` | 9 | The allowance, the overage mechanism and the rate for each provider, in the provider's own unit |
| `managed-db-metering-objects.csv` | 3 | The object each managed-database provider meters (node, broker, storage) |
| `manifest.json` | — | Row counts, column counts, byte counts and md5 for each file, plus the source page it was read from |

For columns, units, source URLs and method for each dataset, see [DATA_DICTIONARY.md](DATA_DICTIONARY.md).

## Querying the tables

`tools/vps_cost.py` reads these CSVs and answers the questions people actually ask before signing a VPS contract. Standard library only, no install step.

```bash
python ../tools/vps_cost.py                  # all published plans, cheapest RAM value first
python ../tools/vps_cost.py --budget 10      # plans at or under $10/month
python ../tools/vps_cost.py --provider OVHcloud
python ../tools/vps_cost.py --terms          # published term totals
python ../tools/vps_cost.py --renewal        # first term vs renewal
python ../tools/vps_cost.py --payments       # payment methods as printed per provider
python ../tools/vps_cost.py --backups        # backup tier terms
python ../tools/vps_cost.py --overage        # traffic allowance and overage mechanism
python ../tools/vps_cost.py --budget 10 --csv
```

## Method

Generated by `export_open_data.py` from the site's rendered public HTML. Nothing is estimated, converted or averaged; where the source says a value is not published, the cell says so. `manifest.json` records row counts, byte counts and md5 for each file, and `tools/check_dataset.py` re-derives those hashes and recomputes the per-unit arithmetic without touching the network.

```bash
python ../tools/check_dataset.py
```

## Caveats

- **A blank cell means the source did not publish that value.** It never means zero.
- **"Not printed" and "Read blocked" are different.** The first is an answer; the second means the page returned an HTTP error and was not read, so nothing about it is claimed.
- **Review dates differ across files.** Check the `review_date` / `checked_on` column, and the source page, before relying on a figure.
- **Prices change.** These are snapshots, not a live feed. Follow the source URL and re-check before buying.
