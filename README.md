# VPS Price Dataset

Published VPS hosting prices and the scripts that recompute their per-unit
figures. The point is to make a "from $X/mo" headline comparable: two plans at
the same monthly price can differ several-fold per GB of RAM, per vCPU, or per
GB of storage.

Every number here is a price or a spec printed on a provider's own pricing
page, transcribed from the public price tables on ServerBudget. No estimates,
no interpolated values, no guessed discounts.

## Files

| Path | Contents |
|---|---|
| `data/vps-plans.csv` | 16 published price rows (14 plans + 2 add-ons) from the homepage ItemList, with the official source URL per row |
| `data/price-per-unit.csv` | 9 rows across three tiers (entry / 2 vCPU 4 GB / high), with vCPU, RAM, storage and the four derived unit prices |
| `data/hidden-costs.csv` | Backup, snapshots, bandwidth overage, billing term and renewal terms for the three providers, as printed on the source page |
| `checklists/vps-cost-due-diligence.md` | A reusable checklist of the questions that change the real first-year cost |
| `tools/rebuild_from_site.py` | Rebuilds `vps-plans.csv` from the homepage JSON-LD. Standard library only, no API key |
| `tools/price_per_unit.py` | Verifies every unit price equals monthly price / spec, then ranks the rows |

## Quick start

```bash
python tools/rebuild_from_site.py
python tools/price_per_unit.py --check-only
python tools/price_per_unit.py --sort usd_per_gb_storage --tier mid
```

`price_per_unit.py` exits non-zero if any published unit figure does not
recompute from the published price and spec. It compares at the precision
used in the CSV, because the published figures are rounded.

## Where the numbers come from

The upstream, human-readable price set is published at https://serverbudget.com/compare.

`vps-plans.csv` is generated by parsing the `ItemList` JSON-LD embedded in that
site's homepage. `price-per-unit.csv` and `hidden-costs.csv` are transcribed
from the `vps-price-compare` table, which states the provider, plan, vCPU,
RAM, storage, monthly price and the source page for each row. The site refers
to a build-time `data/offers.json`; that file is not served publicly, so this
repository reads the rendered public HTML instead.

## Data caveats

- `site_read_date` in `vps-plans.csv` is the source site's own "Newest read"
  label. `rebuilt_at_utc` is when the CSV was generated here. The source site
  also labels some provider groups "Read from the official page on
  2026-10-31"; both labels are kept as published and are not silently
  reconciled.
- An empty cell means the source page did not publish that value. It never
  means zero.
- Introductory and renewal prices are different things. In this dataset,
  ScalaHosting Build #1 is listed at $22.46/mo paid 12 months upfront and
  renews at $54.95/mo (2.45x). For the other providers the source page lists
  no renewal price, so no ratio is computed.
- `type=add-on` rows are options billed on top of a VPS plan, not servers.
- Prices change. Check the provider's own page before making a decision; this
  repository is a reproducible snapshot, not a live feed.
- The per-unit figures are arithmetic on published values. They are not a
  performance benchmark and say nothing about CPU quality, support or uptime.
