# VPS Price Dataset

Published VPS hosting prices, the terms that sit next to them, and the scripts that recompute their per-unit figures. The point is to make a "from $X/mo" headline comparable: two plans at the same monthly price can differ several-fold per GB of RAM, per vCPU, or per GB of storage.

Every number here is a price, a specification or a term printed on a provider's own pricing page, transcribed from the public comparison tables on ServerBudget. No estimates, no interpolated values, no guessed discounts. Where a provider does not publish a figure, the row says so instead of carrying a guess.

## Files

| Path | Contents |
|---|---|
| `data/vps-plans.csv` | 16 published price rows (14 plans + 2 add-ons) from the homepage ItemList, with the official source URL per row |
| `data/price-per-unit.csv` | 9 rows across three tiers (entry / 2 vCPU 4 GB / high), with vCPU, RAM, storage and the four derived unit prices |
| `data/hidden-costs.csv` | Backup, snapshots, bandwidth overage, billing term and renewal terms for the three providers, as printed on the source page |
| `data/open/` | 14 CSV datasets covering plan pricing, add-on costs, renewal terms, promo offers, regional pricing, payment methods, backup tiers, traffic allowances, storage add-ons, overage units and managed-database metering |
| `checklists/vps-cost-due-diligence.md` | A reusable checklist of the questions that change the real first-year cost |
| `tools/rebuild_from_site.py` | Rebuilds `vps-plans.csv` from the homepage JSON-LD. Standard library only, no API key |
| `tools/price_per_unit.py` | Verifies every unit price equals monthly price / spec, then ranks the rows |
| `tools/vps_cost.py` | Queries the `data/open/` tables: plans, term totals, renewal gaps, payment methods, backup tiers, overage rules |
| `tools/check_dataset.py` | Re-derives the `data/open/manifest.json` hashes and recomputes the per-unit arithmetic, offline |

## Quick start

```bash
python tools/price_per_unit.py --check-only
python tools/price_per_unit.py --sort usd_per_gb_storage --tier mid

python tools/vps_cost.py --budget 10
python tools/vps_cost.py --payments
python tools/vps_cost.py --overage

python tools/check_dataset.py
```

`price_per_unit.py` exits non-zero if any published unit figure does not recompute from the published price and spec. It compares at the precision used in the CSV, because the published figures are rounded.

`check_dataset.py` verifies that every file listed in `data/open/manifest.json` still matches its recorded row count, column count, byte count and md5, and that the per-unit arithmetic in `vps-plan-pricing.csv` recomputes. It makes no network request.

## Where the numbers come from

The upstream, human-readable price set is published at https://serverbudget.com/compare.

`vps-plans.csv` is generated by parsing the `ItemList` JSON-LD embedded in that site's homepage. `price-per-unit.csv` and `hidden-costs.csv` are transcribed from the `vps-price-compare` table, which states the provider, plan, vCPU, RAM, storage, monthly price and the source page for each row. The site refers to a build-time `data/offers.json`; that file is not served publicly, so this repository reads the rendered public HTML instead.

The `data/open/` tables are exported from the site's rendered public HTML by `export_open_data.py`, and each row carries the provider URL it was read from.

## Data caveats

- `site_read_date` in `vps-plans.csv` is the source site's own "Newest read" label. `rebuilt_at_utc` is when the CSV was generated here. The source site also labels some provider groups "Read from the official page on 2026-10-31"; both labels are kept as published and are not silently reconciled.
- An empty cell means the source page did not publish that value. It never means zero.
- Introductory and renewal prices are different things. In this dataset, ScalaHosting Build #1 is listed at $22.46/mo paid 12 months upfront and renews at $54.95/mo (2.45x). For the other providers the source page lists no renewal price, so no ratio is computed.
- `type=add-on` rows are options billed on top of a VPS plan, not servers.
- "Not printed" and "Read blocked" are different answers. The first means the provider page did not list the value; the second means the page returned an HTTP error, was not read, and nothing is claimed about it.
- Prices change. Check the provider's own page before making a decision; this repository is a reproducible snapshot, not a live feed.
- The per-unit figures are arithmetic on published values. They are not a performance benchmark and say nothing about CPU quality, support or uptime.
